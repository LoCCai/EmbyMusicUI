# V3 自有播放器开发备忘

开发分支：`codex/v3-player-shell`

## 当前边界

- 自有界面负责播放器视觉、三套布局、设置抽屉、按钮提示和歌词/队列的页面编排。
- Emby 原生会话继续负责播放、暂停、切歌、进度、音量、随机、循环、歌词与队列数据；自有按钮只转发原生事件。
- 前端注入仍限于 `videoosd/lyrics.js` 与 `videoosd/lyrics.css`，不修改通用列表模块。

- [x] 生命周期从歌词内容区提升到整个音乐播放页，歌词/队列切换不退出 V3。
- [x] Hook 原生歌词和播放队列按钮，并为队列提供统一抽屉样式。
- [x] 设置改为独立顶层抽屉，避免层级覆盖和重复实例。
- [x] 工具按钮使用自有 Tooltip，设置内补齐布局、注音、旋转和原生内核说明。
- [x] 按三张参考图重排专辑双栏、唱片机和歌词优先布局。

- [x] 修复设置抽屉被瞬时可见性采样自动关闭；代理外层返回/投屏按钮，并移除原生顶部栏和 OSD 黑色遮罩的视觉残留。
- [x] 播放/暂停改为指针按下立即转发、状态乐观同步和后续点击去重。
- [x] “重新启用增强版”强制使用当前仓库载荷重新生成，避免旧缓存伪装成升级成功。

- [x] 队列抽屉增加视口硬边界和内部滚动锁，超长队列、页面缩放与移动端动态地址栏都不会把抽屉撑出 V3。
- [x] 封面旋转与底部轻量律动绑定 Emby 播放/暂停状态，暂停时冻结且尊重减少动态效果设置。
- [x] 关闭队列或刷新后检测 Emby 遗留的原生队列状态并自动切回歌词数据源，避免歌词区域可见但内容为空。
- [x] 律动扩展为 32 个单元，设置内可记忆地选择紧凑/宽幅/全屏范围、30%–180% 幅度以及回落/曲线/折线/小球/彩虹五种样式。
- [x] 歌词主题和三套播放器布局都改为横向分段按钮，点击即切换，不再使用下拉框。
- [x] 增加媒体信息抽屉和播放页紧凑格式摘要，安全展示路径、容器、大小、日期、音频、内嵌图像与歌词流明细。
- [x] 放宽进度条、放大三枚主播放按钮，并提高浅色布局返回/投屏按钮的对比度。
