# V3 自有播放器开发备忘

开发分支：`codex/v3-player-shell`

## 当前边界

- 自有界面负责播放器视觉、三套布局、设置抽屉、按钮提示和歌词/队列的页面编排。
- Emby 原生会话继续负责播放、暂停、切歌、进度、音量、随机、循环、歌词与队列数据；自有按钮只转发原生事件。
- 前端注入仍限于 `videoosd/lyrics.js` 与 `videoosd/lyrics.css`，不修改通用列表模块。
