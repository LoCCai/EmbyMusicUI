# V4 参数化主题设计系统

更新日期：2026-08-11

## 目标

把播放器从“每套主题一组硬编码坐标”重构为统一设计参数模型。九套内置主题和用户主题使用同一个渲染管线，主题差异只保存在参数、选择项、颜色和信息范围中。

## 已实现

- [x] 九套内置主题迁移到 `PLAYER_PARAMETRIC_PRESETS`，手机公共参数和封面流手机参数独立合并。
- [x] 封面支持单封面/封面流、内外层尺寸、内外圆角、间距、边框、阴影和独立 XY，可组合方套圆、圆套方、方套方、圆套圆。
- [x] 歌曲信息支持宽度、XY、锚点、对齐、标题/歌手/专辑字号、字距、内边距、圆角、模糊、透明度和五种表面样式。
- [x] 歌词支持宽高、XY、内边距、圆角、模糊、透明度、五种表面样式，以及已播放/当前/未播放三态的颜色、字号、字重、字距和行距。
- [x] 频谱支持形态、分析响应、宽高、幅度、密度、XY、旋转、透明度和配色。
- [x] 进度条、音量条支持宽度、轨道厚度、滑块大小和已填充/未填充颜色。
- [x] 底部控制台保持安全区锚定，背景继承主题颜色并应用可调毛玻璃和透明度。
- [x] 用户主题支持新建、保存、复制、重命名、删除，最多保存 24 套；本地存储和 Emby `DisplayPreferences.CustomPrefs` 同步完整主题库与活动主题。
- [x] 媒体信息弹卡支持五种背景表面、颜色、宽高、圆角、模糊、透明度，并可独立启用歌曲、文件、音频、图像、歌词流信息组。
- [x] PC 和横屏弹卡依据触发按钮的实际矩形定位，优先向上、空间不足向下，限制在视口内；媒体内容加载或视口变化后重新计算。手机竖屏使用底部安全抽屉。

## 数据边界

- 主题快照包含 `tuning`、`choices`、`colors`、`mediaFields` 和原有播放器选项。
- 内置主题不可覆盖；调整内置主题后使用“另存为新主题”。
- 无效数字、颜色、枚举、名称和主题 ID 在加载时归一化；损坏的本地主题库不得阻断播放页。
- 底部播放控制继续代理 Emby 原生会话，不创建第二套音频播放内核。
